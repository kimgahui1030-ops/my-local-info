# 카드뉴스 카피 규칙 v1

소재(원문 게시물·뉴스·공공데이터) 하나를 받아 아래 JSON 스펙 하나를 만든다. 근거는 벤치마크 13계정·강의 A/B·유료 도구 분석(docs/instagram-cardnews-plan.md).

## 출력 스펙

```json
{
  "id": "날짜-짧은영문슬러그",
  "brand": "brands.json 의 계정 키",
  "template": "magazine | info",
  "title": "1줄\n2줄 [[강조]]",
  "title_candidates": [{"text": "…", "formula": "숫자 | 따옴표 | 결론 숨김 | 반전 | 질문", "score": 1}],
  "caption_style": "K | G | info",
  "caption": "…",
  "hashtags": [],
  "facts": ["원문 그대로의 숫자·고유명사·장소"],
  "source": {"url": "원문 링크", "account": "원문 계정", "type": "benchmark | news | local-info"},
  "image": {"path": "사진 경로", "source": "pixabay | pexels | own | ai | licensed", "credit": "작가/사이트", "url": "사진 페이지", "focus": "center 30%"},
  "image_queries": ["무료 사진 검색어(영어)"],
  "ai_image_prompt": "특정 장면 재현이 필요할 때만",
  "slides": [{"role": "body | cta", "heading": "…", "emphasis": "…", "body": "…", "image": {}}]
}
```

`image` 는 사진이 없으면 생략한다(브랜드 색 그라데이션으로 대체). `slides` 는 `info` 템플릿에서만 쓴다.

## 제목 (표지)
- 2줄, 줄당 13~16자(띄어쓰기 포함). 줄바꿈은 `\n`.
- 숫자·따옴표·결론 숨김 중 1~2개를 쓴다. 예: "302장", "'이것' 20번", "400% 폭증", "'바뀌었다'".
- 강조 `[[ ]]` 는 1곳만. 노란 글자로 렌더된다.
- 후보 5개를 `title_candidates` 에 점수와 함께 남기고, 가장 높은 것을 `title` 로 쓴다. 강의 A/B 에서는 제목만 바꿔도 조회수가 29~44배 차이 났다.

## 캡션
- **K (국내 뉴스형, 기본)**: `[제목]` 으로 시작 → 배경 → 사건 → 놀라운 점 → 반응 인용 → 결말. 600~700자 기사체. CTA·해시태그 없음.
- **G (해외 수출형)**: 첫 줄은 질문, 이어서 사건 요약.
- **info (정보형 캐러셀)**: `[제목]` + 핵심 요약 2~3문단 + 저장·공유 유도 한 줄. 해시태그는 3~5개까지.
- 윤문: 번역투·AI 말투("~것이다" 남발, "다양한", "효과적인", 과한 쉼표)를 걷어내고 짧은 문장으로 끊는다.

## 사실 고정 (가장 중요)
- 숫자·고유명사·장소·날짜는 원문 그대로 `facts` 에 뽑고, 제목·캡션에 그대로 쓴다. 검수기가 대조한다.
- 원문에 없는 내용을 추론해서 덧붙이지 않는다.
- 과장 금지. 나쁜 예: 원문 "splashes 14 people" → "14명 참사". 원문에 없는 "참사·충격·경악" 같은 말은 쓰지 않는다.

## 이미지
- 원본 게시물 사진은 쓰지 않는다(저작권·오리지널 정책).
- 사물·장소·일반 상황은 Pixabay·Pexels 에서 찾고 `credit` 을 적는다.
- 특정 사건 재현은 AI 이미지로 만들고 `source: "ai"` 로 둔다. 표지에 "이해를 돕기 위한 AI 생성 이미지"가 자동 표기된다.

## 보너스 수익화를 지키는 규칙
- 다른 플랫폼 워터마크·로고가 남은 이미지 금지.
- 남의 게시물을 그대로 옮기지 않는다. 주제와 사실만 가져와 새로 쓴다.
- 협찬(브랜디드 콘텐츠)·콜라보 게시물은 보너스 대상이 아니므로, 보너스용 게시물과 섞지 않는다.
