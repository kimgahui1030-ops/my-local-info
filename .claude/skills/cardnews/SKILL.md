# 카드뉴스 만들기

사용자가 말로 요청하면 화면 없이 바로 결과물을 만든다. 도구는 `cardnews/` 에 있다.

## 준비 (처음 한 번)
```bash
pip install -r cardnews/requirements.txt
python3 -m playwright install chromium   # 이미 브라우저가 있으면 생략
```

## 흐름

1. **소재 확인**: 사용자가 준 링크·캡션·뉴스·데이터에서 사실(숫자·고유명사·장소·날짜)을 먼저 뽑는다. 원문을 볼 수 없으면 추측하지 말고 원문을 달라고 한다. 생활정보형이면 `public/data/local-info.json` 항목을 소재로 쓸 수 있다.
2. **계정·형식 정하기**: `cardnews/brands.json` 에서 계정을 고른다. 없으면 사용자에게 핸들·라벨·대표색을 받아 추가한다. 한 장짜리 이슈는 `magazine`, 단계·목록형 정보는 `info`(5~8장).
3. **카피 쓰기**: `cardnews/prompts/copy_ko.md` 규칙을 읽고 그대로 따른다. 제목 후보 5개를 만들어 점수를 매기고 가장 좋은 것을 쓴다.
4. **이미지**: 사용자가 준 사진이 있으면 쓴다. 없으면 `image_queries` 만 남기고 `image` 를 생략한다(그라데이션 배경). 무료 사진을 쓰면 `credit` 을 꼭 적는다.
5. **스펙 저장**: `cardnews/specs/<id>.json`.
6. **렌더**: `python3 cardnews/render.py cardnews/specs/<id>.json`
   - `✖` error 가 나오면 스펙을 고쳐 다시 렌더한다. 넘침 error 는 문구를 줄여서 해결한다.
   - `△` warn 은 고칠 수 있으면 고치고, 의도한 것이면 보고할 때 이유를 적는다.
7. **확인**: `cover.jpg` 와 각 장을 Read 로 직접 열어 글자 겹침·잘림·어색한 줄바꿈을 눈으로 확인한다.
8. **보고**: 결과 폴더, 고른 제목과 나머지 후보, 남은 warn, 발행 방법을 짧게 알린다.

여러 개를 요청받으면("오늘 5개") 소재마다 1~7을 반복하고 마지막에 한 번에 보고한다.

## 발행 (현재 단계: 수동)
`cardnews/out/<날짜>/<id>/` 폴더를 폰으로 옮겨 이미지를 순서대로 고르고 `caption.txt` 를 붙여넣는다. 발행하면 `meta.json` 의 `published` 에 날짜·계정·게시물 링크를 적는다.

## 하지 말 것
- 원문에 없는 사실을 추론해 덧붙이지 않는다.
- 원본 게시물 사진·다른 플랫폼 워터마크가 있는 이미지를 쓰지 않는다.
- 쿠키·토큰·API 키를 스펙·메모리·저장소에 적지 않는다.
